# Python Cool Projects

A collection of small generative-art and animation projects written in Python, gathered in one place.
All of them are by [iremcnar](https://github.com/iremcnar) and were copied from her public GitHub repos
(source links and the commit each copy was taken from are in the table below).

| Project | What it is | Run it | Source |
|---|---|---|---|
| [eyeTutorial](eyeTutorial/) | Eye → Space: an ASCII-art eye opens, blinks, then the camera dives through the pupil into a starfield and a heart-shaped nebula. `R` restarts, `Esc` quits. | `python eye.py` | [iremcnar/eyeTutorial](https://github.com/iremcnar/eyeTutorial) @ `b4f4b5a` |
